How to buy

  1. Set up a wallet

    Use a wallet such as MetaMask or Trust Wallet. Keep your seed phrase offline and never share it.

  2. Fund it with the network’s coin

    You need the chain’s native coin to swap and to pay network fees.

  3. Open the exchange that lists the pool

    Paste the contract address above into the token field. Check that the address matches exactly.

  4. Set slippage, then swap

    The pool is small, so prices move a lot on each trade. Start with a small amount and raise slippage only as needed.

Read before you trade

  • With only 700+ tokens in the pool, liquidity is very thin. Even small orders can change the price sharply.
  • You may not be able to sell at the price you expect, or at all, if liquidity is removed.
  • Crypto can lose all its value. Only use money you can afford to lose.
